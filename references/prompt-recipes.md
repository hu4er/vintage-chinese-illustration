# 无字插画提示词配方

## 通用结构

`[主体与动作] + [年代服装/道具/环境] + [手绘画种与技法] + [单一完整构图] + [褪色配色] + [细腻纸张颗粒] + [无文字无画框无书页痕迹约束] + [负向词]`

## 必须写进每条提示词的约束段

```
画面中不出现任何文字、字母、数字、书法字、标语、说明文字块；
没有标题区、没有画框、没有分格、没有小剧照拼贴、没有商标、没有水印；
画面铺满整个画幅，没有纸张折痕、撕裂纸边、卷页、旧书页边框或扫描暗角；
单一完整画面，不做海报排版。
```

## 通用正向锚点（择要混入）

- 中国 1950–1980 年代手绘宣传画、水粉画、擦笔年画
- 粗黑勾线，平涂色块带刷痕，面部与衣褶少量晕染
- 褪色朱红、赭黄、灰蓝、墨绿，米黄泛旧纸底
- 细腻纸张颗粒、油墨网点、轻微套色错位、低饱和偏暖的手绘旧印刷色彩；明确不要折痕、页边框与暗角
- 低饱和、偏暖、旧印刷品质感

## 通用负向词

`现代平面设计、极简矢量、3D 渲染、赛博朋克、霓虹灯、高清数码摄影、现代品牌 logo、汽车、手机、过饱和色彩、水印、文字、字母、数字、画框、分格、拼贴小图、书页边框、纸张折痕、撕裂纸边、卷页、旧书扫描件、扫描暗角、多余手指、畸形面部`

## 迭代调整

- 出现文字：加强“无任何文字/字母/数字”并重复一遍负向词，或把 `input_fidelity` 降到 `"medium"` 后重出。
- 出现画框/分格：明确“单一完整画面，没有小剧照画框”，换用 `01`/`05`/`10` 等无框参考图。
- 太像照片：加入“手绘水粉、平涂、粗勾线、非摄影”，换 `02`/`11` 等绘画性参考图。
- 出现折痕或页边框：加强“无折痕、无撕裂纸边、无旧书页边框、无扫描暗角”并重出，不要用旧化脚本补救。
- 质感不足：出图后运行 `scripts/age_poster.py --strength 0.3`，脚本只加细腻颗粒，不会添加折痕或页边。
