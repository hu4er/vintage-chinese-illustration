# 老电影风格插画（无字版）· vintage-chinese-illustration

用 1950–1980 年代中国老电影海报与宣传画的手绘水粉语言作画，但**不生成任何文字与海报装置**：
没有片名、没有说明小字、没有画框分格、没有小剧照拼贴，也没有旧书扫描件的折痕、撕裂纸边、卷页与页边框。

产出是一张画幅铺满、可以直接当文章配图或封面底图的年代感插画。

## 适用场景

- 老电影质感的人物肖像、生活场景、劳动场景、家庭场景配图
- 把已有海报方案改成纯画面（去掉标题与版式）
- 文章封面底图、角色设定图、系列插图

## 安装

**WorkBuddy 客户端**：左侧「技能」→「添加技能」→「上传技能」→ 选择 ZIP → 启用。

**手动安装**：把整个 `vintage-chinese-illustration/` 目录放进 `~/.workbuddy/skills/`
（Windows 为 `C:\Users\<用户名>\.workbuddy\skills\`）。

安装后在对话里说：

> 用老电影插画风格画一张下雨天在巷口等公交

技能会按描述自动匹配触发。

## 工作流程要点

1. **明确参数**：主题、人物/场景、年代服装道具、画幅（默认竖版 2:3，场景可横版）
2. **选参考图**：从 `assets/` 选 1–3 张做图生图，绝对路径传入
3. **写提示词**：主体 + 年代道具 + 手绘画种 + 构图 + 褪色配色 + 细腻颗粒 + 无文字无边框约束 + 负向词
4. **生成**：`ImageGen`，`quality: high`，图生图时 `input_fidelity: high` 保持绘画质感
5. **自查**：确认没有文字、画框、分格、拼贴残留
6. **可选后处理**：`python3 scripts/age_poster.py 输入.png 输出.png --strength 0.3`

> 注意：图像生成会消耗积分（单张约 5–10 积分）。

## 与「老电影海报」技能的区别

| 维度 | vintage-chinese-film-poster | 本技能 |
| --- | --- | --- |
| 文字 | 大号中文片名 + 小字说明 | 完全无文字 |
| 版式 | 主图 + 小剧照画框 + 标题区 | 单一完整画面，无画框无分格 |
| 参考图 | 完整海报翻拍图 | 从海报中裁出的纯绘画区域 |
| 后处理 | 附带中文标题叠加脚本 | 无标题脚本 |
